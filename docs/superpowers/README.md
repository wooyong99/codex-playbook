# Superpowers Working Artifacts

## Purpose

This directory stores design specs and implementation plans created while using Superpowers process skills.

These documents are working artifacts for agentic implementation. They are not product requirements, backend architecture standards, or frontend architecture standards.

## Scope

Included:

- Approved design specs for multi-step implementation work
- Implementation plans that can be executed by an agent or subagent
- Review notes that explain why a workflow was split into tasks

Excluded:

- Project-level product requirements owned by [PRD](../PRD.md)
- Backend architecture rules owned by [Backend docs](../backend/README.md)
- Frontend architecture rules owned by [Frontend docs](../frontend/README.md)
- Review routing rules owned by [Review routing](../review/README.md)

## Document Map

- [Specs](specs/)
- [Plans](plans/)

## Ownership

Specs capture approved design intent for a specific change. Plans translate that intent into executable tasks.

If a spec or plan introduces durable project rules, move those rules into the owning documentation area and link back from the working artifact.
