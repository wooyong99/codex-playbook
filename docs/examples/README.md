# Examples

이 디렉토리는 codex-playbook 사용 예시를 보관한다. 예시는 실제 프로젝트에 바로 적용되는 규칙 원문이 아니다.

## 문서 목록

- [backend/tenant-onboarding-tdd](backend/tenant-onboarding-tdd.md): 테넌트 온보딩 기술설계문서 예시

## 운영 원칙

- 예시는 에이전트가 산출물 형식과 상세 수준을 이해하도록 돕는 참고 자료다.
- 실제 규칙의 단일 출처는 `docs/backend`, `docs/frontend`, `docs/rules`, `.agents/skills` 하위 문서다.
- 특정 도메인, 회사, 제품, 외부 Provider 이름이 들어간 내용은 active policy나 architecture 문서가 아니라 이 디렉토리에 둔다.
- 예시를 실제 프로젝트 규칙으로 승격하려면 관련 영역의 README 문서 맵과 Rule ID를 먼저 갱신한다.
